# Economics Research Journal

本仓库记录《上市公司“存贷双高”异象与股价崩盘风险》的独立实证复现过程。研究关注沪深 A 股上市公司同时持有较高货币资金和较高短期借款的现象，以及它与下一期股价崩盘风险的关系。

原论文：窦超、原亚男、白学锦（2022），《中国工业经济》第 4 期，174–192 页。[DOI](https://doi.org/10.19581/j.cnki.ciejournal.2022.04.004)

## 在 Stata 中查看与运行

项目日志使用 Stata 19。若通过 Git 克隆，先安装 Git LFS，再运行 `git lfs pull` 下载远端可用的大文件。运行脚本前，检查各 `.do` 文件中的 `cd`、`use` 和 `save` 路径，并调整为本机路径。

1. 从 [周收益率预处理脚本](03_stata/00_predo/) 入手，清洗个股与市场周收益率、合并数据并估计周度回归残差。后续以这些残差构造股价崩盘风险指标。
2. 查看 [03_stata](03_stata/) 中的分步脚本，核对财务报表、行业及控制变量的输入与合并关系。运行前以脚本中的输入文件为准。
3. 在 [第 10 步](03_stata/第10步/) 完成样本筛选和缩尾。`回归分析.do` 读取 `02_data/clean/10_2_正式筛选样本_缩尾后.dta`，执行描述性统计、Pearson 相关性分析和基准回归。

## 当前复现口径

回归以 `DH` 为核心解释变量，以 `FNCSKEW` 和 `FDUVOL` 衡量下一期股价崩盘风险。当前脚本使用 `Dturnt_m` 口径的换手率变化，以省份 × 年份固定效应替代 `Index`，并暂用 `DA_csv` 和 `Abacc_csv` 的来源值。这些是当前实现的口径，复现结果仍需与原论文逐项核对。
