## 3. 今日学习与理解（What I Learned）

- **Repository（仓库）**：用于集中管理科研文件和追踪其修改历史。
- **Git**：记录文件版本及变更的版本控制工具。
- **GitHub**：托管 Git 仓库并支持备份、分享与协作的平台。
- **GitHub Desktop**：在图形界面中完成常见 Git 操作的工具。
- **Commit（提交）**：把当前修改记录到本地版本历史。
- **Push（推送）**：将本地提交同步到远程仓库。
- **`main`**：目前仓库使用的主分支名称。

以上为初步认识，后续需要通过实际上传科研日志巩固。
